PAM Vault Diff and Copy

Compare two vaults, or copy one record from the first into the second. Everything happens in this page. Nothing is uploaded, and this page cannot reach the network — see the Content-Security-Policy in the source.

Titles are unique within a PAM vault and are matched exactly, including case. If vault 2 already has a record with this title, you will be asked which to keep.

With no password the result is written as plaintext JSON — readable by anyone and by any program. Delete it when you are done.
